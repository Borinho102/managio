HOW IT WORKS:
-------------

When accessing admin/get_modules/42:
1. Route maps to saas/gb_admin/get_modules(42)
2. Controller loads company #42 info via get_company_subscription_by_id(42)
3. Extracts tenant locale: 42->language || 42->locale || 'en'
4. Extracts tenant currency: 42->currency || saas_default_currency()
5. View uses tenant_locale for localized module titles/descriptions
6. View uses tenant_currency for price display
7. saas_pick_localized() handles fallback automatically (tries tenant locale, then 'en', then first available)

FALLBACK BEHAVIOR:
------------------

Locale Fallback:
- Tenant company->language (e.g., 'fr')
- Tenant company->locale (e.g., 'fr_FR')
- Default: 'en'

Currency Fallback:
- Tenant company->currency (e.g., 'XAF')
- System default via saas_default_currency()

Localized Content Fallback (saas_pick_localized):
- Requested locale (e.g., 'fr')
- English ('en')
- First available locale
- Original string
